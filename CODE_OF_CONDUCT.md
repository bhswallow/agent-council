# Code Of Conduct

Agent Council is a small developer-tool project. The community standard is
simple: be clear, respectful, and practical.

## Expected Behavior

- Treat contributors and users with respect.
- Keep technical disagreement focused on evidence, behavior, and risk.
- Be specific when reporting bugs or security concerns.
- Avoid posting secrets, tokens, private repository content, or unrelated chat
  transcripts.
- Assume maintainers may say no to features that make the tool less manual,
  less auditable, or more surprising.

## Unacceptable Behavior

- Harassment, threats, or personal attacks.
- Publishing another person's private information.
- Repeated off-topic promotion or spam.
- Intentionally misleading users about what Agent Council can execute or
  access.

## Enforcement

Maintainers may edit, hide, or remove issues, pull requests, and comments that
violate this code of conduct. They may also block users from the project when
needed to keep the space usable.

If you need to report a serious issue, use the most private maintainer contact
available to you. Do not include secrets or private repository content in public
reports.
